Prebuilt Python wheel and VSIX install must work offline after dependencies are provisioned; remote introspection explicitly requires network. Cross-version compatibility and security checks remain product gates.

## Measurable responsiveness contract

No upstream numerical SLA was established; these are GraphQL Desk planning budgets chosen to make “responsive” testable. They do not weaken any semantic feature requirement.

- Reference runner: dedicated 4 vCPU, 8 GiB RAM, SSD, no competing benchmark jobs; record exact machine/OS/runtime versions. Each platform runs a correctness/latency smoke check; full benchmark runs on the Ubuntu reference runner. Repeat five cold processes and 100 edits after warmup; publish p50/p95 and max, use monotonic timestamps.
- Small workspace: 100 Python modules, 100 operations, 50 fragments, one 500-type schema. Large workspace: 2,000 modules, 2,000 operations, 1,000 fragments (acyclic chains depth 10), two 2,000-type schemas; average operation 2 KiB; Unicode/CRLF variants. Fixed generator seed 1; retain fixture manifest and counts in eventual benchmarks.
- Debounce 100 ms; from last unsaved edit to version-current GraphQL diagnostics, p95 <=300 ms small / <=750 ms large. Completion/hover response p95 <=150/300 ms. From edit to dependent Pylance hover plus Python diagnostic refresh p95 <=1/2 seconds. Individual large request timeout 5 seconds produces a visible pending/failure state, never a false current result.
- Cold index plus initial types <=3/10 seconds small/large; combined GraphQL Desk Python/Node worker resident memory <=256/768 MiB (measure Pylance separately). Idle work <=1% of one core averaged over 60 seconds after settling; no linear memory growth over 1,000 edits/close/reopen cycles (<=10% post-GC delta).
- Correctness always wins: every timing sample must identify source/schema/config versions; old-version results never count as successes. Schema change invalidates only affected schemas; fragment change only dependents. No persistent cache is required. If added, compare complete output/diagnostics with cache off and exercise every invalidation key before accepting its timing advantage.

These thresholds can be tightened or revised using recorded benchmark evidence and a reviewed decision; they cannot be silently relaxed to claim parity.
