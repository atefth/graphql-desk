## Evidence ledger and support boundaries

- Lower-level GraphiQL adapter passed VS Code extension-host activation, diagnostics/exact ranges, completion, hover, definition, edit refresh and shutdown. This supersedes an earlier standalone protocol fixture's range overrun; embedded Python ranges and full editor behavior remain open.
- One unsaved nullability edit changed Pylance hover/diagnostics after an open generated `.pyi` was updated in memory. Disk-only replacement stayed stale in the tested 15-second window. Broad semantics, cancellation, invalid-buffer recovery, lifecycle and performance remain open; live-typing acceptance has not passed.
- Minimal opaque-marker identity proof passed Pyright 1.1.414 and mypy 2.4.0; runtime identity passed. Nested/transitive/conditional/abstract/list cases remain open. Earlier dataclass wrappers are superseded.
- Saved generator subsets passed; Turms broad-root watch had an unreproduced filename-filter crash. Neither generator proves unsaved live typing or is selected as the core backend.
- Lower-level GraphiQL spike lock reported zero vulnerabilities; older CLI/server tree reported 13 high-severity entries. Historical audits are not current production approval.
- Upstream sources and checked-in tests were inspected, not executed. Published tarballs were not exhaustively compared. Local spike artifacts are not in this checkout; these are reported results, not rerun tests.

## Acceptance detail and provenance

Persisted fixtures must cover exact SHA-256 digests, normalization on/off, transitive fragment closure once, unmask-directive stripping, identical duplicates versus conflicts, stale-ID edits, client typename transforms, named-schema isolation and retained/omitted runtime documents. A manifest alone neither strips runtime source nor implements APQ/server registration. The Python omission/build contract remains an implementation gate.

Schema/CLI fixtures cover SDL/introspection/authenticated URL, HTTP/TLS/timeout/JSON/GraphQL/partial-introspection failures, secret redaction, stable writes, nested config/Windows paths/multiple roots, schema/output collisions, editor/CLI agreement, severity/fail-on-warning/exit codes, annotations and typing freshness. Scan covers every pinned rule over embedded calls/imports with stable terminal/JSON/graph output. Field-use analysis is separately bounded to supported same-file consumption patterns, configurable reserved keys (id, _id, __typename), false positives and mutation/subscription caveats.

Fragment fixtures cover explicit/transitive composition, missing/extra/duplicate dependencies, nested masks, safe fixture closure versus unsafe casts, colocation aliases/re-exports, per-fragment/global unmask, omission versus null, abstract narrowing, alias conflicts and runtime identity. Outer helper wrappers match supported nullable/optional/single-array cases; nested payload list fields still require correct types. Lifecycle fixtures cover Unicode/CRLF, invalid-to-valid recovery, stale-version rejection, close/reopen/restart, cancellation, ownership/undo/save/cleanup, create/delete/rename, multiple roots and cold/warm workspace benchmarks. Any cache must match no-cache results and invalidate schema/source/fragment/config/engine changes.
