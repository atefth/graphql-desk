# Schema declaration primitive

`from graphql_desk.schema_types import render_schema_types` exposes a pure `render_schema_types(schema, *, scalars=(), enums=()) -> str`. It returns deterministic, importable Python declarations; it never writes files or imports project modules. The caller supplies an already constructed schema.

The initial slice emits built-in scalar aliases, Literal enums and recursive TypedDict inputs. It preserves each list/null wrapper and distinguishes optional dictionary keys with NotRequired. Non-null input members with defaults retain the pinned upstream's nullable static compatibility behavior; GraphQL execution may still reject explicit null. This renderer does not validate response data.

Configured mappings use immutable `ScalarMapping(name, input, output)` facts and `(enum_name, qualified_symbol)` pairs. Custom scalars emit separately named Input/Output aliases; inputs and variables use the input alias, result selections use the output alias. Enum mappings replace the static Literal type in both directions. The fixed built-in scalar types remain unchanged. Missing custom mappings, unknown/wrong-kind/duplicate mappings, oneOf inputs and unsafe/colliding emitted declarations raise explicit errors. Only emitted aliases must be safe Python names: a mapped GraphQL scalar named `class` can emit safe `classInput`/`classOutput` aliases.

The renderer validates qualified-symbol syntax and emits deterministic explicit imports. It does not resolve symbol existence, nested-module ambiguity or project type compatibility; those checks remain open under #30. Rendering imports no configured module. Importing the resulting declarations uses their configured imports in the ordinary Python way. Explicit `typing.Any` is accepted only when configured and marked by generated comments; there is no fallback Any or runtime coercion. Doctor/report surfacing remains a follow-up. Keyword input field names are preserved with functional TypedDict declarations.

This is not an operation/result renderer or generated factory. Source ownership, configured output paths, runtime companions, operation Literal overloads, fragments, abstract selections and live generation remain unimplemented. No schema/API/type or live-typing product gate passes from this primitive alone. See the [API/type contract](../contracts/api-and-types.md) for the full required behavior.
