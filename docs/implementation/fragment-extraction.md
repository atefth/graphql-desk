# Fragment extraction

Extraction replaces a complete selected sibling field set with a fragment spread, preserves any selected external fragment dependencies, and validates the transformed document before returning versioned edits.

At module scope, the fragment stays a named Python binding immediately before the query. Inside a direct ordinary or async function body, the fragment `gql(...)` call is placed inline in the operation's `fragments` list. The Python source resolver intentionally rejects function-local fragment-variable references; inline construction keeps both documents in the same function execution and lets the existing resolver validate and index them without widening source-scope inference.

Function-scope support covers direct `Assign` and `AnnAssign` statements whose target is a simple name and whose factory is a trusted `graphql_desk.gql`/`graphql` import, a statically imported `graphql_desk` module alias (`desk.gql`, `desk.graphql`, or `desk.init_graphql`), or a known module-level `init_graphql` result. A module alias must have one binding and may only be used as the receiver of a direct GraphQL Desk factory call; any other reference can escape to a mutator or setter alias, so extraction is refused. The extractor also refuses module-qualified mode when it sees `__builtins__`, the `sys` module registry (including aliases made by simple name assignment), access through `getattr` or `vars` (direct, via `builtins`, imported under an alias, or copied by simple name assignment), zero-argument `vars()` calls, `sys.__dict__`, standard `importlib.import_module` (including imported function and module aliases copied by simple name assignment), or built-in `__import__` calls (direct, via `builtins`, imported under an alias, or copied by simple name assignment). These known lookup routes can return the shared mutable module. The check is deliberately bounded: arbitrary wrappers and attribute-based alias tricks, including `object.__getattribute__`, are not fully analyzed. Nested functions, class bodies, branches, local factory aliases, global/nonlocal declarations, and `locals()`/`vars()` inspection remain unsupported. The provider preserves suite indentation and the source newline style and rejects stale or cancelled edit plans.

This is a bounded #51 slice. Generated/custom factories, function-local nested selection, and inline-only nested-fragment dependency cases remain open; it does not pass a broad parity gate.
